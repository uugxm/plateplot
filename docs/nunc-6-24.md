# Nunc 6 孔与 24 孔模板

两个附件按几何资料读取，文件中的其他文字不作为程序操作指令。仓库只保存模板、
来源指纹和测量方法，不复制厂家 PDF。

## 6 孔：140675

`140675 Rosklide.pdf` 有两页：第 1 页是盖（图号 3224 v11），第 2 页才是板体
（MD6 2nd generation，图号 3223 v10-a）。板体外框标注 **127.76 × 85.46 mm**，
不能用盖上的 55.0 / 63.5 mm 当孔距或边距。

图纸没有标孔径、孔距或 A1 边距。根据用户指示，测量第 2 页俯视图的 PDF 矢量轮廓：
用两轴外框尺寸分别校准，拟合六个可见内圈，旋转为 A1 在左上的 2×3 横向板。
模板 `nunc-140675-schematic` 使用以下 **图纸测量估算**，均按 0.1 mm 取值：

| 项目 | 值（mm） | 依据 |
|---|---:|---|
| 板长 / 板宽 | 127.76 / 85.46 | 图纸标注 |
| 可见内圈直径 | 34.6 | 矢量圆拟合；俯视图不足以明确区分孔口/孔底直径 |
| 横 / 纵孔距 | 40.0 / 40.0 | 六个拟合圆中心 |
| A1 左 / 上边距 | 23.9 / 22.7 | 拟合中心与外框 |

取值精度不是制造公差，不声称这些估算具有 0.1 mm 的测量准确度。已把未标注的
五项尺寸记录在 `assumed_fields`；CLI 和文件元数据会说明存在估算。
两轴标定均约 2.0024 PDF pt/mm，避免将缩小印刷的图直接当作 1:1。

测量记录：[nunc-140675.json](measurements/nunc-140675.json)。重现需要可选依赖
PyMuPDF、numpy、scipy：

```bash
python scripts/measure_nunc_6.py '/path/to/140675 Rosklide.pdf' measurement.json
```

脚本校验附件 SHA-256，固定测量视图及内圈选择范围，不对其他图纸自动识别孔位。

## 24 孔：142485 / 144530

`142485-144530_0508.PDF`，第 1 页，PSS 142485/144530，rev 0508，2008-05-30。
两个货号的板体几何相同，分别保存为 `nunc-142485` / `nunc-144530`。

| 标注 | 意义 | mm |
|---|---|---:|
| A / B | 板体长度 / 宽度 | 127.5 / 85.3 |
| G / H | 孔口 / 孔底直径 | 16.3 / 15.5 |
| K | 孔中心距 | 19.6 |
| C / J | 板高 / 孔深 | 18.8 / 15.7 |

采用 4×6 孔。表格 `NUMBER OF WELLS` 写着 **8**，与标题 `24 ROUND WELL`、
俯视图的 24 个孔及厂家 142485 产品页的 4×6 信息矛盾，记录此不一致，不照抄为 8 孔。
官方确认：[142485 产品页](https://www.thermofisher.com/order/catalog/product/142485)。

图上未标 A1 边距，并明确写着 `NOT TO SCALE`，不从其像素比例反推位置。
暂用 **居中网格假设**：A1_x=(127.5−5×19.6)/2=14.75，
A1_y=(85.3−3×19.6)/2=13.25 mm。这两项在 `assumed_fields` 中保留。

## 样式与选择

继续使用 16 pt 框内行列编号、0.85 pt 孔边线、板内 10 mm 标尺及紧贴标尺的文字；
默认不显示板名、尺寸或页脚。外框圆角、缺角和台阶简化，未把未标注轮廓当作精确尺寸。

```bash
plateplot draw --template 6 --labels well --font-size 16 --output six.svg
plateplot draw --template cell-culture-24 --labels well --font-size 16 --output twentyfour.pdf
```

`6` / `cell-culture-6` 选择 140675 示意模板，`cell-culture-24` 选择 142485。
现有数字 `24` 仍选择 `generic-24`，默认 96 孔板不变。
